# Full‑Stack Note Manager

A minimal full‑stack web app (Node.js + Express backend with a vanilla JS front‑end) that lets you add and list notes.

## Structure

```
note-manager-fullstack/
├── backend/
│   ├── server.js
│   ├── routes/
│   │   └── notes.js
│   └── data/
│       └── notes.json
├── public/
│   ├── index.html
│   ├── app.js
│   └── style.css
├── package.json
└── README.md
```

## Quick start

```bash
npm install
npm start
# Open http://localhost:3000 in your browser
```
